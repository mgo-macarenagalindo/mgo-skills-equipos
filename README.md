# Skills de MG Operations para equipos

Tres skills de Claude para el equipo de un negocio. Una skill es un set de instrucciones que Claude carga cuando lo necesita: la instalás una vez y después la usás con solo pedírselo.

| Skill | Para qué sirve | Descarga |
|---|---|---|
| **Mapa de Fricción Invisible** | Convierte una semana de anotaciones en las 5 cosas que más tiempo le comen al equipo. | [`zips/mapa-friccion-invisible.zip`](zips/mapa-friccion-invisible.zip) |
| **Constructor de SOP** | Te entrevista sobre una tarea y te devuelve el procedimiento escrito, para que otra persona la pueda hacer sin preguntarte. | [`zips/constructor-sop.zip`](zips/constructor-sop.zip) |
| **Analista de KPIs** | Le pegás los números de la semana o del mes y te dice dónde está el problema y qué decidir. | [`zips/analista-kpis.zip`](zips/analista-kpis.zip) |

## Cómo instalarlas en Claude

1. Descargá el `.zip` de la skill (no lo descomprimas).
2. En Claude, andá a **Configuración → Capacidades → Skills** y tocá **Subir skill**. Elegí el `.zip`.
3. Abrí un chat nuevo y pedíselo: por ejemplo, "Usá el Constructor de SOP para documentar cómo damos de alta a un cliente".

> Hace falta tener activada la opción de ejecución de código en Claude para usar skills.

Cada skill trae un `ejemplo-de-output.md` con un resultado de muestra.
