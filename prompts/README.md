# Prompts

Prompts para copiar y pegar en Claude (o en tu IA). Uno nuevo cada dos semanas.

- [Copiloto Operativo](copiloto-operativo.md): le contás un problema operativo y te devuelve una regla con dueño por paso y el mensaje para el founder.
- [Diagnóstico Operativo](diagnostico-operativo.md): te hace una entrevista corta y te devuelve el mapa del negocio, los 3 movimientos de esta semana y el número para el founder.
